**Marisol Bay — El calor de la costa**: a top-down 2D open-world crime game in a fully original fictional city. Play as Milo Cruz, a getaway driver $40,000 in debt to fixer Vera Solano. Drive and steal cars, outrun the police across a 0–5 star wanted system (with helicopter response from 4 stars), fight the rival Tide Kings, and run 6 story missions — from a first delivery to robbing the Bay Bank. Living city with traffic, pedestrians, a minimap, HUD, synthesised WebAudio music and sound, and save/continue.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node --experimental-strip-types main.ts
```
